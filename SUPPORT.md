# Support

Before opening a report, check the usage and configuration instructions in [`README.md`](README.md).

For reproducible bugs and feature requests, open a GitHub Issue in this repository and include:

- the Action version;
- the Portal version or commit, when relevant;
- the runner operating system;
- the relevant workflow excerpt with all secrets removed;
- the error message and expected behavior.

Do not include ingest tokens, upload tokens, OAuth secrets, Blob URLs, or private test evidence.
Report security vulnerabilities through GitHub private vulnerability reporting instead of a public
Issue.
